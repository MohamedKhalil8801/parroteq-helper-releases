# ParrotEQ Helper releases

Releases only. ParrotEQ Helper is the small app that lets [ParrotEQ](https://parroteq.vercel.app) play its EQ in your computer's EQ app (Equalizer APO on Windows; EasyEffects or PipeWire on Linux). Get it from the ParrotEQ website: Listen, Play everywhere.

Each release has the Windows program, the Linux program and its installer, `SHA256SUMS`, and `latest.json` with its minisign signature (`latest.json.minisig`). The helper checks that signature against the key built into it before it installs an update.
